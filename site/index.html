Quick start¶

This is a very basic Modelica code to simulate the motion of a spring - mass - damper system. Check out more amazing content at the tutorial sections or find out how to get started below.

model simpleSpringMass
  parameter Real M = 5;
  parameter Real k = 12;
  parameter Real C = 8;
  Real x;
  Real v;
initial equation 
  x = 1;
equation
  der(x) = v;
  M*der(v) + C*v + k*x = 0;
annotation(
    experiment(StartTime = 0, StopTime = 10, Tolerance = 1e-06, Interval = 0.002));
end simpleSpringMass;
