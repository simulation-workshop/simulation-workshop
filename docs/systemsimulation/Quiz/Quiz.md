# Quiz on Modelica

Quiz:
    - Q1: What is the name of modeling approach where relationship between variables are non-directional?
        - A: Acausal modeling
        - B: Parametric modeling
        - C: Iterative modeling
        - Answer: A

    - Q2: What should be the relation between number of variables and number of equations in a model?
        - A: Number of variables should always be greater than equations
        - B: They should always be equal
        - C: There are no such relationships
        - Answer: B
